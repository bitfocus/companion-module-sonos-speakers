## SONOS

**Available commands**

- Set volume
- Adjust volume
- Next/Previous Track
- Play/Pause device
- Set muted (toggle/mute/unmute)
- Load stream URI

**Variables** (per device)

- `volume` (number), `volume_text`, `muted`, `state`, `group`, `name`, `streamUri`
- `track_title`, `track_artist`, `track_album`

Variables can be used in expressions and in action options, for example to build buttons that show the current track.
